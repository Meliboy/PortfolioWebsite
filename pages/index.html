Projects


GlucoTrack Enterprise Platform

Fall 2025

During my fall semester, 3rd year, I had the exciting opportunity to travel to Pittsburgh for the first time for the SteelHacks Hackathon. As a team of 4, we conducted user interviews with a mother who had to navigate life with a daughter who was diagnosed with Type-1 Diabetes. Using this as our motivation, we created features including a meal tracker, personal AI agent to assist with non-medical inquiries, and a data-tracking page that syncs with a user's CGM device; and then, allows the user to view their blood-glucose trends visually.

  • Developed a functional health application prototype at SteelHacks, with data-entry logs, and a meal tracker.
  • Orchestrated an intelligent AI agent for the prototype using LangChain and the Gemini API, implementing RAG to answer non-medical user inquiries.
  • Scaled the hackathon concept into a technical proposal, system design, and HIPAA-compliant data constraints.
  • Designed specifications for an interoperability middleware layer (GlucoBridge) to normalize gathering data from CGM devices.

This experience taught me the importance of conducting user interviews with real-possible users of an application that I want to develop. Seperating features into different pages, and team mates is a tactic to allow for rapid development which was necessary in real-life engineering scenarios. Ultimately, I learned that impact which technology can have on improving the medical lives of people and hope to continue learn the safegaurds & research which truly allow software applications to improve lives.
